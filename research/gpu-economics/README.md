# GPU Economics: reproducibility and limitations

Source: Rahil Mittal, *gpu-price-history*, commit `ee8820dd90d7715d8bb57cee03fb0882706d76c5`, https://github.com/rahilmittal1/gpu-price-history. The panel created by the author is CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/); underlying providers' terms remain applicable. The author's paper was under review. Access 2026-11-12. Dataset revision 3 through 2026-09. Do not treat reconstructed catalog snapshots as transaction prices, guaranteed capacity or independent contemporaneous observations.

The full 76,351-row input is not redistributed here; obtain `data/rent/rent_panel_monthly.csv` from the pinned repository commit. The included `data/a100_matched_source_rows.csv` contains only the 38 rows used in the exploratory example, preserving the upstream columns. `python3 analyze.py` re-filters this sample, reports missing months, staleness, first and last snapshots. Reproducing selection from the full panel requires changing the input file in the script. A full source rebuild requires upstream raw data that are not all redistributed and was not independently rerun.

Coverage: Lambda, us-east-1, A100-80GB SXM, neocloud on-demand, SkyPilot catalog snapshot, no upstream flag, exact `gpu_8x_a100_80gb_sxm4` instance field. First and last observations use snapshots 2023-02-25 and 2026-08-03 respectively; 38 rows across 43 monthly periods, 5 missing, 9 with staleness >30 days. +86% is a single reconstructed series, not industry age decay, causation, contract pricing or proof of customer demand. Staleness may reflect unchanged catalog files and is not direct proof the quote is wrong.

`model.py` contains illustrative on-demand and simplified take-or-pay cash flows; no real contract is implied. No-tax default deliberately separates depreciation from cash taxes. It does not estimate IRR, replacement/alternative asset NPV or economically optimal retirement. Economic life cannot be inferred from payback alone. `python3 -m unittest -v test_model.py` validates cost units, monotonicity and distinct contract formulas.

MLPerf v6.0 was inspected; a directly comparable A100/H100/B200 same-model, same scenario, same software and pricing sample has not been validated. The article does not label hypothetical throughput as measured. The dataset aggregator's computed per-accelerator throughputs are not official or verified MLCommons metrics; result-specific citation and trademark rules apply. RouteLLM is evidence for conditional task routing, not evidence of demand for older GPUs.

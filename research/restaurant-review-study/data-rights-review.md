# 공개 데이터 이용 및 원천 확인 메모

확인일: 2026-11-09. 이 문서는 확인한 문서와 미확인 사항을 구분한 연구 메모이며 법률 의견이 아니다.

## 제공자와 원천의 구분

[데이터 제공자 공개 페이지](https://seoulrestaurants.com/data/)는 자체 데이터셋에 CC BY 4.0과 출처 표시를 명시한다. 그러나 데이터가 어떤 경로와 권한으로 각 플랫폼에서 수집됐는지, 제3자가 원천 데이터를 재배포하거나 파생 집계를 공개할 권리가 어느 범위까지 포함되는지는 이 표기만으로 확인할 수 없다. 원본·개별 식당 기록의 저장소 재배포는 하지 않았다. 집계 그래프의 게시 가능성 역시 원천 권리와 수집 경로를 확인한 후 판단한다.

## 네이버

[네이버 자동화 수집 관련 정책](https://policy.naver.com/rules/disclaimer.html)은 규정된 예외를 제외한 자동화 수단을 이용한 서비스 또는 API 서버 접근·정보 수집을 금지한다고 명시한다. [네이버 API 약관](https://developers.naver.com/products/terms/)에는 API로 받은 결과의 허용 범위를 벗어나는 복제·저장·가공·배포 등에 대한 제한이 있다. 다만 제공자가 실제 네이버 API를 사용했는지 알 수 없으므로 해당 API 약관을 이 데이터셋의 수집 과정에 직접 적용해 위반 여부를 단정할 수 없다. 이 연구에서는 네이버 자동 수집이나 우회 접근을 하지 않았다.

## 카카오

[카카오 Local API 문서](https://developers.kakao.com/docs/ko/local/dev-guide)는 장소·주소 검색 및 좌표 정보를 설명한다. [카카오디벨로퍼스 서비스 약관](https://developers.kakao.com/terms/ko/site-terms)과 해당 서비스별 조건을 확인해야 한다. 제공자가 어떤 API나 수집 경로를 이용했는지, 데이터의 저장·파생 집계 이용에 어떤 계약 조건이 적용되는지 확인되지 않았으므로 허용 여부를 단정하지 않는다. 공식 문서의 장소 검색 응답만으로 본 데이터셋의 `kakao_rating_count` 정의나 데이터 계보가 검증되는 것은 아니다.

## 출판 전 확인할 질문

1. 제공자가 `naver_visitor_score`와 `naver_visitor_reviews`를 수집한 실제 출처·기간과 수집 시각은 무엇인가? 0과 0.5는 결측 또는 실제 값인가?
2. 카카오의 `kakao_rating_count`는 수치 평점에 참여한 건수인가, 별도의 텍스트 리뷰 건수인가?
3. 각 플랫폼 원천 권리와 약관상 개별 기록 및 이 연구의 집계·시각화를 공개할 수 있는가?
4. `verified`는 해당 날짜에 각 플랫폼 점수를 실제로 다시 수집했다는 의미인가? 이전 자료가 포함되는가?

제공자에게 문의하는 초안은 작성할 수 있으나 발송은 별도 지시가 필요하다.

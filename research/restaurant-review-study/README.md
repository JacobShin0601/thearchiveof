# 식당 리뷰 연구: 재현 절차와 확인되지 않은 사항

이 디렉터리는 작업 중인 탐색 분석이다. 원본을 재배포하지 않는다. Python 3.12 환경에서 numpy, pandas, scipy, matplotlib, statsmodels, tabulate를 설치하고 제공자의 [JSON](https://seoulrestaurants.com/data/restaurants.json)을 별도로 다운로드한 뒤 `python analysis.py --input /path/to/restaurants.json --output /path/to/results`를 실행한다. `python -m unittest discover -s tests`로 기본 계산을 검증한다.

## 분석한 스냅샷

- 출처: Seoul Restaurants, https://seoulrestaurants.com/data/ (제공자 표기 CC BY 4.0). 원천 플랫폼의 재사용 권리는 별도 확인이 필요하다.
- 원본 `updated`: August 2026. 다운로드 2026-11-09 KST; 파일 크기 571,239 bytes; SHA-256 `d773be04b93421ec2c70186a6260f3e461781918b4f7964a111d75dff18f9901`. 원본은 이후 갱신될 수 있으므로 다른 해시의 결과를 같은 스냅샷으로 표시하지 않는다.
- 352 레코드, 중복 ID 0, 이름과 도로명 주소 중복 0. 모든 `verified`는 2026-08-12이나 이것이 플랫폼별 평점 수집시점과 동일한지는 알 수 없다.
- 네이버 6개 결측, 3개 범위 밖(0 두 건, 0.5 한 건). 유효범위 밖은 분석에서 결측 처리한다. 0이 결측 표식인지는 미확인이다.
- 점수 공식의 오차 허용치 0.015 기준 Local Score 불일치 2건: `sr-1827198361`, `sr-1738156523`; 둘 다 네이버 점수 0이며 Local Score는 카카오 점수와 같다. Gap Score 불일치 0건. 계산은 원본 수치 기준이다.
- 네이버 점수의 산출 경로·포함 기간과 방문자 리뷰 수가 별점 평가 수와 같은지는 미확인이다. 따라서 연구에서는 제공자 수록 점수라 부르며 리뷰 수를 베이지안 표본 크기로 사용하지 않는다.
- 신뢰도 0.9 이상 필터는 민감도 비교를 위한 임의의 기준이며, 제공자의 점수가 실제 매칭 정확도를 뜻한다는 보장은 없다. 원천별 이름·주소 15~20건 대조와 영업 여부는 미완료다.
- 225개는 Google 대 Local Score Gap 배지 적격 수다. 플랫폼 간 유효 점수 쌍은 범위 검증 후 342개다.

## 해석

카카오 3.5에 대해서는 `<`, `=`, `>`, `≥`를 별도로 출력한다. 백분위 기준은 엄격 ECDF `P(X < t)`와 포함 ECDF `P(X ≤ t)`로 함께 기록한다. 무작위 표집이 아니므로 신뢰구간은 선택된 관측치의 재표집 변동을 보여줄 뿐 서울 전체에 대한 일반화 근거가 아니다. 관찰된 평점 차이는 음식의 질이나 리뷰 이벤트의 인과효과가 아니다.

추가 민감도 분석은 `python robustness.py --input /path/to/restaurants.json --output /path/to/robustness.json`으로 실행한다. 유효 쌍 전체 342곳 평균 차이는 0.5309점, 제공자 신뢰도 0.9 이상 289곳은 0.5307점, 카카오 평가 수 30 이상 276곳은 0.5493점, 100 이상 130곳은 0.5487점이다. 양 플랫폼의 절대 차이가 1점 이하인 295곳은 0.4138점이다. 후자는 결과값 자체로 식당을 거르는 탐색적 분석이므로 제외된 식당을 오류로 간주해서는 안 된다. 신뢰도 0.9 역시 임의 기준이며 실제 매칭 정확도의 검증된 확률이 아니다.

리뷰 수별 분포는 `python review_volume.py --input /path/to/restaurants.json --output /path/to/volume.json`으로 재현한다. 카카오 351곳의 수록 평가 수 중앙값은 68건, 평균은 약 139.4건, 99분위는 1,201건이다. 평점과 수의 스피어만 상관은 -0.0686이다. 네이버의 343곳 방문자 리뷰 수 중앙값 1,072건은 별점 평가자의 수가 아니라 제공자 수록 방문자 리뷰 수이며 카카오 평가 수와 정의가 서로 다를 수 있다. 집계된 식당별 평점의 분산은 개별 평가의 분산이나 신뢰구간이 아니다.
